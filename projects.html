Netflix Content Strategy Analysis

Python · Data Analytics · Jul – Sep 2024

Netflix decides what to release and when largely on instinct and internal precedent — so I set out to see how much of that could actually be backed by data. I pulled Netflix's content catalog into Python and looked for patterns across three angles: which genres actually held audience attention, how release timing moved engagement, and where the platform seemed to be over- or under-investing. The output wasn't just a set of charts — it was a handful of concrete content strategy recommendations, each one traceable back to a specific trend in the data rather than a hunch.

Alzheimer's Disease Prediction Through ML & TL Techniques

XGBoost · Python · Dec 2023 – Mar 2024

Alzheimer's is most treatable when it's caught early, and early signs are exactly what's easiest to miss in dense neuroimaging data. I trained an XGBoost model on neuroimaging scans to flag those early indicators, using transfer learning techniques to get meaningful signal out of a limited dataset. A model output alone isn't useful to a clinician, though, so I also built a lightweight admin interface where predictions could actually be reviewed and interpreted — the goal was something a doctor could plausibly use, not just a number in a notebook.
